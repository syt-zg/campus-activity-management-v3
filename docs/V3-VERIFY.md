## 三、验证结论

| 需求 | 验收指标 | 结果 |
|---|---|---|
| 资格校验生效 | 不符合资格的学生报名被拒绝 | 通过：返回“该活动限定「计算机」…” |
| 取消原因留痕 | 取消后原因可统计 | 通过：流水与统计均出现“时间冲突（与实验课冲突）” |
| 递补确认窗口 | 递补后出现待确认与截止时间 | 通过 |
| 超时释放顺延 | 逾期名额自动回收并递补下一位 | 通过：流水出现“系统自动释放”，后一位转为正式参加 |
| 出席记录 | 可标记出席并进入统计 | 通过：统计出现“已出席 1” |
| 名单导出 | CSV 含表头与出席列 | 通过 |
| 归档保留 | 删除后不再展示但历史保留 | 通过 |
| 运行统计/日志 | 指标、漏斗、趋势、事件可查 | 通过 |
| 原有功能回归 | 三角色主路径仍可用 | 通过 |
